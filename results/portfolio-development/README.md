# Initial portfolio evidence

Read [the research review](../../docs/PORTFOLIO_INITIAL_REVIEW.md) for the scientific interpretation and [the runbook](../../docs/PORTFOLIO_RUNBOOK.md) for desktop execution.

- `validation.json`: executed scope, code/source identities, artifact hashes, tests, measured costs and unexecuted native work.
- `evidence-map.json`: historical evidence categorized before the new campaign.
- `prior-art-source-manifest.json`: consulted source URLs and retrieval hashes.
- `full-protocol.json`: the predeclared 40-job desktop campaign; not a completed result.
- `development/`: exact copies of five verified bounded CPU numerical/prototype stages, with a publication index.
- `smoke/portfolio-atlas.pdf`: 52-page atlas from the corrected 14-stage CPU smoke.
- `smoke/chart-data.json.gz`: exact source-linked chart records, including model metadata, measurements, learning curves, failures and claim scope.
- `smoke/provenance/`: original execution summaries and seals. This curated subset omits checkpoint/reference banks and is not itself a resumable workflow.
- `first-integration-attempt/`: original v1 summaries and incurred operational work, including the scaling implementation defect corrected before v2.

All 48 primary smoke advantage claims are **NA** because only two independent fields were evaluated. GPU tests were collected, not executed. Prototype correctness, job completion and a useful scientific result are different outcomes. Timing measurements describe this cloud CPU environment; no RTX 4090 timing, total energy bill, or published FNO superiority is inferred.
